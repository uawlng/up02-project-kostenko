НАЙДЕННЫЕ ОШИБКИ:

1. NameError: name 'COLOR_PRIMARY_BG' is not defined
   Причина: имя цвета в styles.py не совпадало с тем, что в catalog.py
   Решение: Заменила на COLOR_MAIN_BG

2. ImportError: cannot import name 'font' from 'styles'
   Причина: в catalog.py импортировался font, но в styles.py его нет
   Решение: убрала font из импорта

3. IndentationError: unexpected indent
   Причина: строка image_path имела неправильный отступ (1 пробел вместо 4)
   Решение: выровняла отступы до 4 пробелов


4. Приложение падало при пустом названии
   Причина: не было защиты от пустых значений
   Решение: name = product.name if product.name else "[Без названия]"
